# Zgui
A Ui/Gui Libary made for Zenex

# Docs

<h3>Window</h3>

```Lua
Zgui:SetTitle("") -- Title
Zgui:SetTitleIcon() -- Title Icon
Zgui:SetGame("") -- Game Name
Zgui:SetVersion("") -- The version of the Script
Zgui:SetLogo() -- The icon Button
```
<h3>Tab</h3>

```Lua
local  = Zgui:Tab("") -- Making the Tab
-- Example
local Main = Zgui:Tab("Main")
```
